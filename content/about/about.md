# About

Palliative Brain is a living clinical reference designed for rapid bedside retrieval and longitudinal learning in palliative medicine.

The project emphasizes:

- practical symptom management
- communication
- prognostication
- systems navigation
- evidence-informed care
- conceptual linking across clinical domains

Built using:

- Quartz
- Obsidian
- Markdown
- GitHub Pages

## Philosophy

The goal is not encyclopedic completeness.

The goal is fast, clinically useful cognitive support.
